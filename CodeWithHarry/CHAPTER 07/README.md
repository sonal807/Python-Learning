# 🤔 What are Loops?

A **loop** is a programming construct that repeatedly executes a block of code until a specified condition becomes false or until all elements of an iterable have been processed.

Instead of writing the same code multiple times, loops allow us to write it once and execute it as many times as required.

Loops make programs shorter, cleaner, and more efficient.

---

# ❓ Why are Loops Needed?

Imagine printing numbers from **1 to 100**.

Without loops, you would have to write:

```python
print(1)
print(2)
print(3)
...
print(100)
```

This is repetitive and inefficient.

Using a loop:

```python
for i in range(1, 101):
    print(i)
```

The same task is completed using only two lines of code.

Loops help us:

- Execute repetitive tasks automatically.
- Reduce duplicate code.
- Improve readability.
- Save development time.
- Process collections of data efficiently.
- Build scalable applications.

---

# 🔄 Flow of Execution

The execution of a loop follows these general steps:

1. The loop starts.
2. A condition is checked (or the next item is selected in a sequence).
3. If the condition is satisfied, the loop body executes.
4. Control returns to the beginning of the loop.
5. The process repeats until the condition becomes false or all elements are processed.
6. The program continues with the next statement after the loop.

---

# 📝 Types of Loops in Python

Python provides two primary looping statements:

- `while` Loop
- `for` Loop

Both are used to perform repetitive tasks, but they are suitable for different situations.

---

# 1️⃣ while Loop

The **`while` loop** repeatedly executes a block of code **as long as a specified condition remains `True`**.

It is commonly used when the number of iterations is **not known in advance**.

### Syntax

```python
while condition:
    # code
```

### Example

```python
count = 1

while count <= 5:
    print(count)
    count += 1
```

**Output**

```
1
2
3
4
5
```

### Working

- The condition is checked before every iteration.
- If it evaluates to `True`, the loop executes.
- When the condition becomes `False`, the loop stops.

Since the condition is checked before execution, the `while` loop is known as an **entry-controlled loop**.

---

# 2️⃣ for Loop

The **`for` loop** is used to iterate over an iterable such as a string, list, tuple, dictionary, set, or a sequence generated by `range()`.

It is commonly used when the number of iterations is already known or when traversing a collection.

### Syntax

```python
for variable in iterable:
    # code
```

### Example

```python
fruits = ["Apple", "Banana", "Mango"]

for fruit in fruits:
    print(fruit)
```

**Output**

```
Apple
Banana
Mango
```

### Working

- Python selects one element from the iterable.
- The loop variable stores that element.
- The loop body executes.
- Python automatically moves to the next element.
- The loop ends after the last element has been processed.

Unlike the `while` loop, the `for` loop automatically handles iteration.

---

# 💡 Choosing Between `for` and `while`

Use a **`for` loop** when:

- Iterating over a string.
- Traversing a list or tuple.
- Processing dictionary keys or values.
- Working with `range()`.
- The number of iterations is known.

Use a **`while` loop** when:

- The number of iterations is unknown.
- Waiting for user input.
- Repeating a task until a condition changes.
- Building menu-driven programs.
- Creating interactive applications.

# 🔢 The `range()` Function

The `range()` function is used to generate a sequence of numbers. It is commonly used with the `for` loop when you want to execute a loop a specific number of times.

Instead of creating a list of numbers, `range()` generates numbers one by one, making it memory efficient.

---

## Syntax

```python
range(start, stop, step)
```

### Parameters

- **start** *(Optional)*: The starting value of the sequence. Default is `0`.
- **stop** *(Required)*: The ending value (not included in the sequence).
- **step** *(Optional)*: The increment or decrement between numbers. Default is `1`.

---

## Example 1: Using Only Stop

```python
for i in range(5):
    print(i)
```

**Output**

```
0
1
2
3
4
```

---

## Example 2: Using Start and Stop

```python
for i in range(2, 7):
    print(i)
```

**Output**

```
2
3
4
5
6
```

---

## Example 3: Using Step

```python
for i in range(2, 11, 2):
    print(i)
```

**Output**

```
2
4
6
8
10
```

---

## Example 4: Negative Step

```python
for i in range(10, 0, -2):
    print(i)
```

**Output**

```
10
8
6
4
2
```

# 🔁 Nested Loops

A **Nested Loop** is a loop inside another loop.

The inner loop executes completely for every iteration of the outer loop.

### Syntax

```python
for i in range(3):
    for j in range(2):
        print(i, j)
```

**Output**

```
0 0
0 1
1 0
1 1
2 0
2 1
```

---

## Example: Multiplication Table (1 to 3)

```python
for i in range(1, 4):
    for j in range(1, 11):
        print(i, "x", j, "=", i * j)
    print()
```

This prints the multiplication tables for 1, 2, and 3.

# ⚠️ Common Mistakes

### ❌ Forgetting to Update the Counter in a `while` Loop

```python
count = 1

while count <= 5:
    print(count)
```

This creates an **infinite loop** because `count` never changes.

Correct:

```python
count = 1

while count <= 5:
    print(count)
    count += 1
```

---

### ❌ Incorrect Range

```python
for i in range(1, 5):
    print(i)
```

Many beginners expect the output to include `5`, but it doesn't.

Output:

```
1
2
3
4
```

Remember: the `stop` value is **not included**.

---

### ❌ Modifying a Collection While Iterating

Avoid adding or removing elements from a list while looping over it directly, as it can produce unexpected results.

# 🚦 Loop Control Statements

Sometimes, we need to change the normal execution of a loop. Python provides special statements to control how loops behave.

The three loop control statements are:

- `break`
- `continue`
- `pass`

These statements help us terminate, skip, or leave a placeholder inside loops.

---

# 🛑 The `break` Statement

The `break` statement is used to **immediately terminate** a loop.

When Python encounters a `break` statement, it exits the loop completely and continues executing the next statement after the loop.

### Syntax

```python
break
```

### Example

```python
for i in range(1, 11):
    if i == 6:
        break
    print(i)
```

**Output**

```
1
2
3
4
5
```

### Real-Life Example

Imagine searching for a particular file in a folder.

As soon as the file is found, there is no need to continue searching.

The loop stops immediately using `break`.

---

# ⏭️ The `continue` Statement

The `continue` statement skips the current iteration and immediately moves to the next iteration of the loop.

Unlike `break`, it does **not** terminate the loop.

### Syntax

```python
continue
```

### Example

```python
for i in range(1, 6):
    if i == 3:
        continue
    print(i)
```

**Output**

```
1
2
4
5
```

### Real-Life Example

Suppose you are checking attendance.

If one student's record is missing, you skip that student and continue checking the remaining students.

---

# ⏸️ The `pass` Statement

The `pass` statement is a **null statement**.

It does nothing when executed.

It is mainly used as a placeholder where Python expects a statement syntactically but no action is required yet.

### Syntax

```python
pass
```

### Example

```python
for i in range(5):
    if i == 3:
        pass
    print(i)
```

**Output**

```
0
1
2
3
4
```

### Real-Life Example

While developing a project, you may know that some code will be added later.

Instead of leaving the block empty (which causes an error), you can temporarily use `pass`.

Example:

```python
def login():
    pass
```

---

# 🔄 The `else` Clause with Loops

Python provides an optional `else` block that can be used with both `for` and `while` loops.

The `else` block executes **only when the loop finishes all its iterations normally**.

If the loop is terminated using the `break` statement, the `else` block is **not executed**.

This feature is commonly used in searching algorithms, where the `else` block runs only if the desired item is not found.

---

## Syntax (`for-else`)

```python
for variable in iterable:
    # code
else:
    # executes after the loop finishes normally
```

### Example

```python
for i in range(5):
    print(i)
else:
    print("Loop Completed Successfully")
```

**Output**

```
0
1
2
3
4
Loop Completed Successfully
```

---

### Example with `break`

```python
for i in range(5):
    if i == 3:
        break
    print(i)
else:
    print("Loop Completed Successfully")
```

**Output**

```
0
1
2
```

Since the loop was terminated using `break`, the `else` block was skipped.

---

## Syntax (`while-else`)

```python
while condition:
    # code
else:
    # executes when the condition becomes False
```

### Example

```python
count = 1

while count <= 3:
    print(count)
    count += 1
else:
    print("Loop Finished")
```

**Output**

```
1
2
3
Loop Finished
```

# ♾️ Infinite Loops

An **Infinite Loop** is a loop that never ends because its condition always remains `True`.

### Example

```python
while True:
    print("Hello")
```

This loop continues forever unless interrupted manually or terminated using `break`.

---

## Avoiding Infinite Loops

Always ensure that the loop condition eventually becomes `False`.

Correct Example

```python
count = 1

while count <= 5:
    print(count)
    count += 1
```

# ⚠️ Common Mistakes

### ❌ Forgetting the update statement in a `while` loop

```python

while count <= 5:
    print(count)
```

This creates an infinite loop.

Correct:

```python
count = 1

while count <= 5:
    print(count)

```

---

### ❌ Using `break` instead of `continue`

Beginners sometimes use `break` when they only want to skip one iteration.

Remember:

- `break` → Ends the loop completely.
- `continue` → Skips only the current iteration.

---

### ❌ Leaving empty blocks

Incorrect

```python

```

This produces an error.

Correct

```python
if True:
    pass
```

---

### ❌ Assuming `else` always executes

The `else` block only runs if the loop finishes normally.

If the loop exits because of a `break`, the `else` block is skipped.

---

- Use `continue` to skip unwanted iterations.

# 📚 Important Functions Used with Loops

## `range()`

Generates a sequence of numbers.

```python

    print(i)
```

---

## `len()`

Returns the number of elements in a sequence.

```python
name = "Python"

for i in range(len(name)):
    print(name[i])
```

---

## `enumerate()`

Returns both the index and the value while iterating.

```python
fruits = ["Apple", "Banana", "Mango"]

for index, fruit in enumerate(fruits):
    print(index, fruit)
```

**Output**

```

1 Banana
2 Mango
```

---

## `items()`

Returns both keys and values from a dictionary.

```python
student = {
    "Name": "Sonal",
    "Age": 20
}

for key, value in student.items():
    print(key, value)
```

---

## `keys()`

Returns only the dictionary keys.

```python
for key in student.keys():
    print(key)
```

---

## `values()`

Returns only the dictionary values.

```python
for value in student.values():
    print(value)
```
